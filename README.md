# OptiFarm (PHP + MySQL + Bootstrap 5)
1. Install XAMPP, start Apache + MySQL.
2. Copy this folder to `htdocs/optifarm`.
3. phpMyAdmin -> Import `database.sql` (creates the `optifarm` database + sample data).
4. Edit DB credentials in `config.php` if needed (default: root / no password).
5. Open http://localhost/optifarm
